# Deploy (GitHub Pages, free)
1. Create a public repo named exactly `KadamVrushali.github.io`.
2. Upload index.html, photo.jpg, resume.pdf, robots.txt, sitemap.xml (not preview.html).
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/root`.
4. Live in ~1 min at https://kadamvrushali.github.io

# Get it on Google
1. https://search.google.com/search-console → Add property → URL prefix → https://kadamvrushali.github.io/
2. Verify with the "HTML tag" method: paste the <meta name="google-site-verification" ...> line into <head> of index.html, push, click Verify.
3. Sitemaps → submit `sitemap.xml`. URL inspection → Request indexing.
4. Put the site link on LinkedIn, GitHub profile and Instagram bio; those links help Google find and rank it for your name.
