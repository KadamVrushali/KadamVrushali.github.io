## Built with

- Plain HTML, CSS and a little vanilla JavaScript, with no frameworks and no build step
- Pixel sprites (husky, hearts, icons) drawn on `<canvas>` from small character grids
- Fonts: Pixelify Sans, Nunito and VT323 (Google Fonts)
- Hosted on GitHub Pages

## Run it locally

```bash
git clone https://github.com/KadamVrushali/KadamVrushali.github.io.git
cd KadamVrushali.github.io
python3 -m http.server 8000
# open http://localhost:8000
```

## Updating

Edit `index.html` and push to `main`. GitHub Pages redeploys in about a minute.
When you update the content, also change the `<lastmod>` date in `sitemap.xml` so Google re-crawls it.
